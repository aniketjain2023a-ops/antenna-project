# MetaOpt-AI — Antenna Design Explorer

**Machine-learning-based antenna performance prediction and geometry optimization**
Student: Aniket Jain · Registration No. 23BEC0470

MetaOpt-AI is a local website, with a **React** frontend and a **FastAPI** backend, around a Python ML
pipeline. It loads verified antenna datasets, trains regression surrogates, predicts performance
for a design, optimizes the geometry with Differential Evolution, and compares the results, with
every record stored in SQLite.

> **Scientific honesty.** The models predict *simulated* (METU-SIMPL, Ansys HFSS) or *synthetic*
> responses. They do not solve Maxwell's equations. Optimized geometries are **ML-selected
> candidates** that have not been simulated or measured. See `DATASET_COMPARISON.md`.

---

## 1. Run it on a Mac

Prerequisites: **Python 3.11+** and **Node.js 20.19+ or 22.12+** (`node --version`; install it from
nodejs.org or with `brew install node`).

```bash
cd "antenna project"
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt

python scripts/prepare_public_datasets.py   # once: download + preprocess + train METU-SIMPL (~2 min)
./start.sh                                   # builds the website and serves it at http://127.0.0.1:8000
```

`start.sh` runs `npm install` (first time only) and `npm run build` in `frontend/`, then
`python -m backend`. FastAPI serves both the API (`/api/...`) and the built website.

**Development mode** (hot reload), in two terminals:

```bash
# terminal 1 — API on port 8000
source .venv/bin/activate
uvicorn backend.main:app --reload --port 8000

# terminal 2 — website on port 5173 (proxies /api to port 8000)
cd frontend
npm install
npm run dev            # open http://localhost:5173
```

API documentation (generated by FastAPI): http://127.0.0.1:8000/docs

## 2. The website

| Page | What it does |
|---|---|
| **Home** | Five-step workflow; dataset cards (with provenance badge, sample count and best model per target); unavailable sources with the reason; selected dataset's quality, inputs/targets, provenance and checksum; **model training** (Dummy, Random Forest, Gradient Boosting, optional Extra Trees) with the held-out test metrics |
| **Design & Optimize** | Dataset selector (only datasets whose pipeline completed). Parameter form generated from the selected dataset's inputs, units and valid ranges, with inline validation. **Live prediction** of every target with approximate uncertainty and model metrics; save to history. **Differential Evolution** optimization: objective, optional constraint, parameters to vary, bounds, baseline. Baseline vs ML-selected candidate side by side, convergence chart, nearest actually-simulated design |
| **Results** | Test R² across datasets and targets; full metrics table; per-model actual-vs-predicted, residuals, permutation and impurity importance; optimization history; CSV downloads |

Design: the installed Apple Design skill (`~/.claude/skills/apple-design`) guided the system font
with size-specific tracking, the translucent navigation material, instant press feedback, inline
validation, live feedback, the light/dark palette and the reduced-motion, reduced-transparency
and contrast fallbacks. Tokens are in `frontend/src/index.css`.

## 3. Architecture

```
antenna project/
├── frontend/                 React 19 + Vite + TypeScript + Tailwind CSS 4 + shadcn/ui + Recharts
│   └── src/
│       ├── pages/            home.tsx · design.tsx · results.tsx      (the three pages)
│       ├── components/ui/    shadcn/ui components (button, card, select, tabs, segmented, …)
│       ├── components/       app shell, charts (Recharts), shared blocks
│       └── lib/              typed API client, dataset context, formatting
├── backend/                  FastAPI app (main.py routes, service.py glue), python -m backend
├── services/workflow.py      orchestration reused by the API, scripts and tests
├── ml/  optimization/        training, evaluation, prediction, uncertainty, importance; Differential Evolution
├── database/                 SQLAlchemy models, migrations, repository (SQLite)
├── datasets/                 synthetic generator; public/ (METU-SIMPL, Zenodo) download + preprocessing
├── scripts/                  prepare_public_datasets.py, run_demo_pipeline.py
├── reporting/ visualization/ PDF report and Matplotlib figures (used by the scripts)
├── tests/                    pytest: database, data, ML, optimization, public data, API; e2e/ browser test
└── data/ models/ results/    SQLite DB, datasets, trained models, metrics and figures
```

Flow: React → `fetch('/api/…')` → FastAPI → `services.workflow` / `ml` / `optimization` → SQLite and
joblib model files.

| Endpoint | Purpose |
|---|---|
| `GET /api/datasets` | datasets with features, targets, quality, active models; unavailable sources |
| `GET /api/datasets/{id}/preview`, `/experiments` | first rows; all trained models with metrics |
| `POST /api/datasets/{id}/train` | train models (one per target), select active models by CV R² |
| `POST /api/datasets/{id}/predict` | predict all targets for one design (`save: true` stores it) |
| `POST /api/datasets/{id}/optimize` | Differential Evolution on the surrogate; saved as a run |
| `GET /api/experiments/{id}/diagnostics` | test-set points and feature importance |
| `GET /api/results/summary` | metrics across datasets and optimization history |
| `GET /api/export/{datasets,experiments,predictions,optimizations}.csv` | CSV downloads |
